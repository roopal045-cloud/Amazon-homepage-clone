# 🛒 Amazon Homepage Clone

A front-end clone of the Amazon homepage built using HTML and CSS. This project recreates the layout, navigation bar, product sections, and overall user interface of Amazon to practice responsive web design and modern front-end development techniques.

## 🚀 Live Demo

👉 https://amazone-homepage-clone.netlify.app/

## 🚀 Features

- Amazon-inspired homepage layout
- Responsive navigation bar
- Search bar design
- Hero section/banner
- Product category cards
- Footer section
- Responsive design for different screen sizes
- Clean and organized code structure

## 🛠️ Technologies Used

- HTML5
- CSS3

Amazon-Homepage-Clone/

## 🎯 Project Objective

The goal of this project was to improve front-end development skills by recreating a real-world e-commerce homepage. It focuses on:

- HTML page structure
- CSS Flexbox and Grid
- Responsive layouts
- UI replication
- Web design fundamentals

## ▶️ Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/amazon-homepage-clone.git
```

2. Open the project folder.

3. Launch `index.html` in your browser.
